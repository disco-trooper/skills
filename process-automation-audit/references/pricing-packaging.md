# Pricing And Packaging

## Offer Types

Treat ranges below as directional, not timeless. If the user asks for market validation, current rates, competitor pricing, or whether a price is outside the market, browse current sources and cite them.

### Quick Scan

Use for small clients or early uncertainty.

- 1 call,
- limited input review,
- short recommendation memo,
- no detailed process map,
- no pilot specification.

Typical range: low tens of thousands CZK.

### Single-Process Audit

Use when one process is the likely starting point.

Includes:

- input review,
- 1-3 stakeholder interviews,
- current-state map,
- pain/risk analysis,
- automation opportunity list,
- recommended pilot scope.

Typical range: 35-75k CZK.

### Digitalization Roadmap

Use when leadership wants to compare multiple domains.

Includes:

- process inventory,
- prioritization matrix,
- dependencies,
- recommended sequence,
- first pilot recommendation.

Typical range: 60-120k CZK.

### Pilot

Use only after enough audit clarity exists.

Includes:

- prototype/demo or narrow working workflow,
- test data handling,
- acceptance criteria,
- results review,
- next implementation recommendation.

Typical range: higher tens to low hundreds of thousands CZK.

## Pricing Logic

Price based on:

- decision value,
- avoided wasted implementation,
- complexity,
- stakeholder count,
- data sensitivity,
- ERP/SAP dependency,
- deliverable quality,
- urgency.

Do not price by "how many pages" or by analysis effort alone.

## Scope Levers

To lower price, reduce:

- number of processes,
- number of interviews,
- sample size,
- report depth,
- roadmap breadth,
- technology assessment depth.

Do not reduce price while keeping the same deliverables.

## Packaging Pattern

Present fixed-scope options:

| Option | Use when | Output |
| --- | --- | --- |
| Quick Scan | early trust or light orientation | short directional memo |
| Audit | one process needs clarity | decision-ready process analysis |
| Roadmap | many possible areas compete | prioritized plan |
| Pilot | use case is already clear | proof on real data |

Lead with the option that best matches the client's uncertainty.

## Price Conversation

Reply in the user's language. For Czech clients, use formal but natural Czech unless the user asks for a different tone.

If asked for implementation cost early:

```text
I can give a responsible implementation estimate only after we know the real process and scope. The audit is designed to make that estimate meaningful instead of speculative.
```

### Czech

```text
Odpovědný odhad implementace umím dát až ve chvíli, kdy známe reálný proces a rozsah. Audit slouží k tomu, aby pozdější odhad nebyl spekulace.
```

If price feels high:

```text
The audit is meant to prevent a much more expensive mistake: building the wrong workflow or over-integrating too early. If we need a lower price, I would reduce the audit scope rather than keep the same output at a lower fee.
```

### Czech

```text
Smysl auditu je předejít dražší chybě: stavbě špatného workflow nebo příliš brzké integraci. Pokud potřebujeme nižší cenu, zúžil bych rozsah auditu, ne stejný výstup za nižší cenu.
```
