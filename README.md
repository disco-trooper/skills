# Skills

Evidence-based training skills for AI agents.

## Skills

| Skill | What It Does |
|-------|--------------|
| [cycling-training](./cycling-training/) | Power zones, periodization, indoor training, nutrition for cyclists |
| [hypertrophy-training](./hypertrophy-training/) | Volume, nutrition, exercises, recovery for muscle growth |

## Install

```bash
npx skills add disco-trooper/skills
```

One skill only:

```bash
npx skills add disco-trooper/skills --skill cycling-training
```

## Compatibility

Works with Claude Code, Cursor, OpenCode, Codex, and other [Agent Skills](https://agentskills.io)-compatible tools.
